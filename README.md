# ABM SALES-MANAGER - REACT + TYPESCRIPT

- Aplicación SPA (Single page application)
- Se ejecuta del lado del cliente
- Desarrollada con Vite ReactJS TS 

> [!IMPORTANT]
> Tener NodeJS instalado v24.22.1

## Installation y puesta en marcha
- Ejecutar el comando ```npm install``` para obtener las libreróas necesarias
- Modificar el archivo ```src\services\api.js``` con la dirección correspondiente del servidor back

### Ejecución de development
 - Ejecutar ```npm run dev```, por defecto levanta la aplicación en el puerto 5173
 
### Build para production
 - Ejecutar ```npm run build```, genera una versión ya compilada en la carpeta ```dist```
